# 🚀 Full-Stack TodoApp

TodoApp, Spring Boot ve React kullanılarak geliştirilen, modern ve kullanıcı dostu bir tam teşekküllü CRUD uygulama projesidir.

## ✨ Özellikler

- 📝 Görev ekleme, listeleme ve silme
- ✅ Tamamlandı / Tamamlanmadı durumu (Toggle)
- 🗂️ Dinamik filtreleme sekmeleri (Tümü / Aktif / Tamamlanan)
- 🐳 Docker destekli kalıcı PostgreSQL veritabanı altyapısı
- ⚡ Şık ve duyarlı (responsive) Tailwind CSS arayüzü

## 🛠️ Kullanılan Teknolojiler

- **Backend:** Java 17, Spring Boot, Spring Data JPA, PostgreSQL
- **Frontend:** React, Vite, Tailwind CSS
- **Altyapı:** Docker & Docker Compose
